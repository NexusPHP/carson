Install Carson

A GitHub App that manages your repository like a butler.

Personal account

Creates a Carson App in your personal account with the required permissions pre-filled.

GitHub App names must be globally unique. Use something like "Carson @ your-handle".

Organisation

Creates a Carson App in your organisation. You must be an admin of the org.

The App name auto-fills as you type the org name. Edit it if you want something different.

Or set up manually

If you prefer to register the App by hand, follow the Setup guide in the README. The required permissions live in app-manifest.json.
