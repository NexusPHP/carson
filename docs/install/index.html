Carson posts comments and check runs as the bot login above. Treat this as the App's GitHub handle.

Follow the steps in order. Each step shows the value it needs and where it goes.

Add the App ID as a repository secret

In the repository or organisation where Carson will run, go to Settings → Secrets and variables → Actions and add a secret named CARSON_APP_ID with this value.

Add the private key as a repository secret

On the same page, add a secret named CARSON_PRIVATE_KEY with the full PEM contents, including the -----BEGIN and -----END lines. Download the .pem file to keep a copy, or copy the contents straight into the secret.


    


    

      
Install the App on your repositories

      
From the App settings page, choose Install App and select the repositories Carson should act on. The same page lets you regenerate the private key or review the App's permissions later.

      Open App settings on GitHub
      

        Optional: set the App icon
        
Carson ships with a butler icon you can use as your App's avatar. Save the image, then upload it under Display information → Logo on the App settings page. GitHub does not expose an API for App avatars, so this is the only way to set it.

Commit the workflow file

      
Save as .github/workflows/carson.yml in each repository where Carson should run. It reads the two secrets from steps 1 and 2. Trim triggers you do not need.

      
name: Carson

on:
  pull_request_target:
    types: [opened, synchronize, reopened, edited]
  pull_request_review:
    types: [submitted]
  push:
  issues:
    types: [opened, edited, closed, reopened, labeled]
  issue_comment:
    types: [created]
  schedule:
    - cron: '0 0 * * *'

jobs:
  carson:
    runs-on: ubuntu-latest
    steps:
      - uses: NexusPHP/carson@<commit-sha> # v1.2.0
        with:
          app_id: ${{ secrets.CARSON_APP_ID }}
          private_key: ${{ secrets.CARSON_PRIVATE_KEY }}


      
    


    

      
Commit the configuration file

      
Save as .github/carson.yml on the default branch and list the subscribers you want enabled. See SUBSCRIBERS.md for the full list. Carson reads its config from the default branch only, so pull requests cannot alter the bot's behaviour.

      
version: 1
subscribers: []
